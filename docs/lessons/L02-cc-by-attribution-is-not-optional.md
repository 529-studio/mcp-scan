# L02: CC BY Attribution Is Not Optional

## Context & Problem

A public dataset under CC BY 4.0 can be used commercially, but only if the user gives appropriate credit, links the license, and indicates changes. Teams often copy the data into a product and drop the attribution because "it is free".

## Root Cause

The license is read as "free to use" instead of "free to use under conditions". Attribution is treated as a nice-to-have rather than a condition of the grant.

## Solution

- Keep a credits page or `NOTICE` file with the dataset name, authors, and license link.
- State whether the data was modified (filtered, sampled, labeled).
- Do not use the dataset owner's name or logo to imply endorsement.
- Keep the license text with any redistribution.

## Verification

- The credits page exists and is reachable from the product.
- The license link resolves.
- The modification statement is accurate.
- A redistribution includes the license and notice.
