# L08: Landing Pages Must Not Sell Unbuilt Features

## Context & Problem

A pricing table is a promise. If Pro and Team are listed with a price and a "Join waitlist" link that looks like a buy button, a visitor can reasonably believe the product exists. The first support request exposes the gap.

## Root Cause

The page is designed for the future product, not the current one. "Coming soon" is buried in small print, or omitted because it weakens the pitch.

## Solution

- Mark unbuilt tiers as `WAITLIST` or `ROADMAP` in the tier label.
- Keep the buy CTA only on the available tier.
- Put the alpha status in the hero.
- Add a FAQ answer that states what is available today.
- Re-check the page on every release.

## Verification

- The available tier has a real link.
- The waitlist tiers say waitlist.
- The hero says alpha.
- A visitor can tell what they can use now.
