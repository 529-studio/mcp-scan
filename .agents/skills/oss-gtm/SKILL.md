# OSS GTM

The motion is open-source + public report + vendor badge. No cold calls.

## When to activate

- Planning a launch, report, or badge program.
- Writing a README, landing page, or launch post.
- Choosing channels for a new feature.

## Artifacts

### Open source

- A one-liner that a developer understands in five seconds.
- A 30-second quick start.
- Real output, not a mock.
- A GitHub Action.
- Issue templates for new rules and false positives.

### Public report

- A narrow, defensible dataset (20 configs).
- Responsible disclosure before publication.
- Aggregate findings, no exploit details.
- A checklist readers can use.
- A landing page and a PDF.

### Vendor badge

- Clear criteria.
- Free for the first ten vendors.
- No payment for a pass.
- Limited scope: the scanned config, not the whole product.
- Revocation on a high/critical finding.

## Channels

| Channel | Use |
|---|---|
| GitHub | Source of truth, stars, issues |
| Hacker News | One launch post, real demo |
| Reddit / MCP Discord | Technical feedback |
| LinkedIn | Report and badge announcements |
| Newsletter sponsorship | Later, after case studies |
| Marketplace | GitHub, AWS, cloud |

## Copy rules

- Lead with the problem, not the product.
- Use concrete findings, not adjectives.
- Mark alpha and unbuilt features.
- No "100% secure".
- No fake urgency.

## Metrics

- Stars, installs, report downloads.
- Inbound emails/DMs.
- Design partners.
- Paid accounts.
- Badge applications.

## Guardrails

- Responsible disclosure.
- No vendor logo without permission.
- No exploit code.
- No astroturfing.
- No claims that the scanner replaces a pentest.
